# 🚀 تطبيق إنجاز | Enjaz App
> **منصة ذكية وتفاعلية لإدارة المهام والتنافس الإيجابي اللحظي مدعومة بـ Supabase**  
> *An interactive, real-time productivity & task challenge platform powered by Supabase*

### 📌 نبذة عن المشروع (About The Project)
**إنجاز (Enjaz App)** هو تطبيق إنتاجية يعتمد على أسلوب التلعيب (Gamification) لتعزيز روح الإنجاز اليومي. يتميز النظام بمرونة تامة تسمح بالمنافسة الفردية أو الجماعية (شخصين أو أكثر)، مع نظام متقدم لا يكتفي بعدّ المهام، بل يقيس **قوة ووزن كل مهمة** ويحدث النتائج ونسب التقدم لحظياً (Real-time).

### 🛠️ التقنيات الأساسية (Tech Stack)
* **قاعدة البيانات والباك إند:** [Supabase](https://supabase.com) (PostgreSQL Database).
* **التزامن اللحظي:** Supabase Realtime Channels لتحديث الشاشات فوراً.
* **حماية البيانات:** Row Level Security (RLS) لعزل وتأمين بيانات كل متنافس.
