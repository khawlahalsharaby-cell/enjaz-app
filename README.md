# 🚀 تطبيق إنجاز | Enjaz App
> **منصة تفاعلية ذكية لإدارة المهام والتنافس الإيجابي اللحظي مدعومة بـ Supabase**  
> *An interactive, real-time productivity & task challenge platform powered by Supabase*

---

### 📌 نبذة عن المشروع (About The Project)
**إنجاز (Enjaz App)** هو تطبيق إنتاجية مصمم بأسلوب التلعيب (Gamification) لتعزيز الحماس والإنجاز اليومي. يتميز بمرونة كاملة تتيح التنافس الفردي أو الجماعي (بين شخصين أو أكثر) مع نظام ذكي يقيس **قوة ووزن المهام** وليس فقط عددها، مع حساب نسب الإنجاز وتحديث النتائج لحظياً (Real-time).

### 🛠️ التقنيات المستخدمة (Tech Stack)
* **قاعدة البيانات والباك إند:** [Supabase](https://supabase.com) (PostgreSQL Database).
* **التزامن اللحظي:** Supabase Realtime Channels.
* **الأمان:** Row Level Security (RLS) لحماية خصوصية بيانات المتنافسين.
* **الواجهة:** تصميم عصري متجاوب يدعم الأجهزة الذكية.
